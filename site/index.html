按住 ⌘，按一个字母，
应用就过来了。

不必在几十个窗口里翻找。右 Command 按住不放，面板列出每个应用的字母， 按下去、松开，它就切到前面。每个字母都可以按你的习惯改。

看看怎么用 自己构建一个

这不是截图：字母、面板、切换结果都能真的按。

切换应用 松开 ⌘ 切换 · Esc 取消
Option + 字母：把字母分配给前台应用

三个动作，一次呼吸的时间。

触发键是右 Command，不是左 Command —— 它离字母键更近，也不和常用快捷键打架。

1

按住右 ⌘

面板从当前窗口上方浮起，列出正在运行的应用、它们的字母，以及各有几个窗口。

2

按一个字母

字母按应用名字自动分配；你想固定的，改成自己顺手的那个键就行。

3

松开

应用来到前台。没运行的会被启动；选错了按 Esc，什么都不会发生。

它记住你的习惯，而不是让你记住它。

下面每一条都在这台机器上跑过：不是设想，是行为。

字母就地改

点一下字母格，直接按你想要的键。不用先删再分配，也不用手输 bundle id。

忽略一个应用

列表里每行都有「忽略」。被忽略的应用不再出现在切换面板，也不会占着某个字母。

盲操模式

打开后按住 ⌘ 不弹面板，直接按字母切换。看不见，但更快。

只数真正的窗口

应用常驻的小对话框不算窗口。单窗口的应用，不会再被写成「2 windows」。

中英双语

默认中文，设置里一键切到 English，立即生效，选择会记住。

授权不会每次失效

用固定的签名身份，重建应用后辅助功能与输入监控的授权仍然有效。

快，是因为少做了两件事。

每次按住 ⌘ 都要列举一次运行中的应用。最初这一趟要 64 毫秒、90 KiB —— 其中大部分花在把每个应用的图标编码成 PNG，以及逐个查询窗口。 盲操模式下两者都不需要，于是同一趟变成 18 毫秒、1 KiB。

数字来自本机 12 个运行中应用的实测，在同一台机器上测量。

完整列举：图标 + 窗口数64 ms · 90 KiB
盲操：跳过图标与窗口18 ms · 1 KiB

自己构建，一分钟。

需要 macOS、Go 1.27.3 与 Xcode Command Line Tools。 第一次运行会给出一张固定的签名身份 —— 有了它，之后重建不会让系统授权失效。

终端 
# 只跑一次：创建本机固定的代码签名身份
$ make signing-identity

# 构建 .app（Swift helper 会一起编译并签名）
$ make build

# 产物
#   dist/rcmd-nsgo-0.1.0-macos_arm64/rcmd-nsgo.app
# 拖进「应用程序」即可

首次启动会要两项权限

辅助功能用来读取与移动其他应用的窗口，输入监控用来接住全局按键。 两者都授予之后，按住右 ⌘ 才有反应。

如果系统设置里明明是打开的、应用却说没有权限，通常是因为那个开关属于更早的构建。 用 make signing-identity 固定签名后，这种情况只会发生一次。
